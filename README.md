# Linktree — Antonio van Londen

Meine persönliche Startseite: eine schlichte Seite, die alle meine Profile und meinen Lebenslauf an einer Stelle bündelt.

**Live ansehen:** https://imthefake.github.io/Linktree_Antonio/

## Womit gebaut

- HTML und CSS, ohne Framework
- Der Glas-Effekt der Karte über `backdrop-filter`
- Icons von [Font Awesome](https://fontawesome.com/)
- Veröffentlicht über GitHub Pages

## Aufbau

```
index.html          die Seite
style.css           das Aussehen
images/             Profilbild und Hintergrund
pdf/lebenslauf.pdf  mein Lebenslauf zum Herunterladen
```

Mein erstes eigenes Projekt, das öffentlich erreichbar ist.
